How the evidence was built

A decision system, not a leaderboard notebook.

The project separates model development, threshold design and final evaluation in time. No threshold is tuned on the locked holdout.

01

Profile the operating reality

Measure rare-event prevalence, identity coverage, entity concentration, missingness and weekly instability before modelling.

02

Build leakage-safe baselines

Benchmark rules and a calibrated linear model with temporal validation and entity-deduplicated daily alert metrics.

03

Challenge and falsify

Compare nonlinear models, run feature-family ablations and bootstrap daily metric differences instead of trusting a single score.

04

Translate score to action

Route allow, step-up, review and block actions under capacity and cost assumptions; stress-test three operating postures.

Honest limitations

What this portfolio does not pretend

  • IEEE-CIS labels are a competition proxy, not confirmed production chargebacks.
  • Cost and intervention effectiveness are explicit scenarios, not observed causal effects.
  • Device and identity fields are partially observed; incremental value is uncertain.
  • Shadow mode and human investigation would be required before live decisioning.
